# HealthData-Valuator | 医疗数据资产价值计量器

本项目旨在构建一套标准化的医疗数据资产价值评估系统。通过科学的指标体系与加权算法，为全国各级医院提供数据资产估值服务。

## 项目定位

* **当前版本**: V1.0 (基础版)
* **核心目标**: 实现“指标输入 -> 自动计算 -> 结果展示”的闭环流程
* **交付日期**: 2026年x月x日 

---

## 技术选型

为了兼顾开发效率与系统稳定性，本项目采用全栈分离架构：

* **前端**: Vue 3 + Element Plus + Vite (侧重 PC 端兼容，适配移动端浏览器)
* **后端**: Python FastAPI (高性能异步框架，自动生成交互式 API 文档)
* **数据库**: MySQL 8.0 (使用 SQLAlchemy ORM 进行对象关系映射)
* **协作工具**: Gitee/Github 、Apifox (接口联调)、Cursor

## 快速开始


```bash
# 克隆项目
git clone [项目地址]

# 后端启动
cd backend
pip install -r requirements.txt
uvicorn main:app --reload

# 前端启动
cd frontend
npm install
npm run dev

后端 API 默认运行在 http://localhost:8000，前端开发服务器默认运行在 http://localhost:5173

```
